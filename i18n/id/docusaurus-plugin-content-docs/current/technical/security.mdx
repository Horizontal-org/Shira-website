# Keamanan
Keamanan dan privasi pengguna Shira sangat penting bagi kami.

Kami mengumpulkan jumlah data minimal absolut tentang pengguna Shira, dan hanya mengumpulkan data yang kita perlukan untuk kekuatan fitur Shira dan kemampuan

Kami menerapkan langkah-langkah standar industri untuk memastikan kerahasiaan, integritas, dan ketersediaan semua data pengguna. Untuk informasi lebih lanjut tentang bagaimana kami menangani data di Shira cloud (pada https://space.shira.app dan https://quiz.shira.app), lihat [polis privasi kami](/privacy-policy). Organisasi dengan kekhawatiran privasi khusus dapat [self-host instance mereka sendiri Shira](/self-hosting).

Selain itu, Shira adalah open-source sehingga siapa pun bisa [review kode yang menyalakan aplikasi](https://github.com/Horizontal-org/shira).

Akhirnya, sebelum merilis fitur baru utama, kami mengaudit keamanan komisi oleh perusahaan keamanan pihak ketiga independen. Hasil dari audit ini tersedia secara publik:
- Juli 2023: [audisi keamanan oleh Subgraph di Shira 1.0](/assets/subgraph-audit-july-2023.pdf)
- June 2026: [security audit by Convocation Research and Design Labs on Shira 2.0](/assets/convocation-audit-june-2026.pdf)
