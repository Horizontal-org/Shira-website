# Mengelola Ruang Anda

Ruang adalah tempat pusat di Shira untuk membangun kampanye pendidikan phishing Anda:
- Ruang adalah di mana Anda ** menciptakan kuis, mengelola para pelajar, dan melihat hasilnya ** untuk para pelajar Anda.
- **Di Ruang Anda, Anda dapat memiliki banyak [Quizzes](/quizzes)**. Misalnya, Anda dapat membuat kuis berfokus pada phishing email dan yang lain pada SMS phishing; atau Anda dapat membuat kuis ke anggota tim baru onboard, dan membuat kuis terpisah untuk melatih tim Anda setiap kuartal.
- **Each quiz terdiri dari [Questions](/questions)**. Pertanyaan menunjukkan email atau pesan dan meminta pelajar untuk memutuskan apakah pesan terlihat seperti phishing atau terlihat sah. Para pelajar juga memiliki pilihan untuk menjawab "Saya tidak tahu". Anda dapat membangun pertanyaan Anda dari goresan atau tarik template dari [ Perpustakaan](/templates).
- **Someone yang mengambil kuis disebut [Learner](/learners)**. Ada Peneliti Terdaftar (apa yang perlu bergabung dengan Ruang Anda untuk mengambil kuis pribadi) dan Peneliti Anonim (anyone yang mengambil kuis publik menggunakan URL kuis).
- Setelah para pelajar mengambil kuis, ** bagian [Results](/results) menunjukkan bagaimana mereka melakukannya di kuis**.

## Pengaturan ruang {/* #settings */}
Di pengaturan Ruang Anda, Anda dapat:
* memperbarui alamat email yang terkait dengan akun anda
* memperbarui kata sandi anda
* mengelola [rencana anda, berlangganan, dan informasi pembayaran](/plans)

## Login {/* #permissions */}
* Secara default, hanya satu pengguna admin dapat mengakses ruang. [Enterprise](/pricing) pengguna dapat menambahkan lebih banyak admin (masing-masing dengan akun mereka sendiri dan kredensial) dengan [kontak kami](/contact).
* Hanya admin dapat mengakses Dasbor Ruang Anda. Learner tidak pernah memiliki akses ke dashboard Space, kuis, atau Hasil.

Tabel ini merangkum apa yang para pelajar dan admin bisa dilakukan di Shira Space:
| Login                    | Learn | Login |
| ------------------------ | ----- | ----- |
| Login                    | Yes   | Yes   |
| Login                    | No    | Yes   |
| Buat dan Mengelola       | No    | Yes   |
| Lihat Hasil              | No    | Yes   |
| Buat dan Mengelola Ruang | No    | No    |


## Menyiapkan ruang Anda {/* #deleting-your-space */}
Saat ini tidak mungkin untuk menghapus Ruang Anda tanpa bantuan kami. Jika Anda ingin menghapus Ruang Anda, [kontak kami di sini](/contact).
