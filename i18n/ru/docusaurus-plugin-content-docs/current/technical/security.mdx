# Безопасность
Безопасность и конфиденциальность пользователей Shira очень важны для нас.

Мы собираем абсолютное минимальное количество данных о пользователях Shira, и только собираем данные, необходимые для питания функций и возможностей Shira

Мы осуществляем отраслевые стандарты для обеспечения конфиденциальности, целостности и доступности всех пользовательских данных. Для получения дополнительной информации о том, как мы обрабатываем данные об облаке Шира (http://space.shira.app и https://quiz.shira.app), пожалуйста, смотрите [наша политика конфиденциальности](/privacy-policy).

Кроме того, Shira является open-source, чтобы любой мог [обзор кода, который управляет приложением](https://github.com/Horizontal-org/shira).

Наконец, прежде чем выпустить основные новые функции, мы проводим аудит безопасности независимыми сторонними охранными фирмами. Результаты этих проверок доступны для общественности:
- Июль 2023: [Ревизия безопасности на сайте Subgraph on Shira 1.0](/assets/subgraph-audit-july-2023.pdf)
- June 2026: [security audit by Convocation Research and Design Labs on Shira 2.0](/assets/convocation-audit-june-2026.pdf)
