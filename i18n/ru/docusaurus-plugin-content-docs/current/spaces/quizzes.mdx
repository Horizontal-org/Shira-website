# Тесты

Тест — центральный компонент образовательной инициативы или программы по фишингу. Shira позволяет вам создавать собственные тесты в соответствии с конкретными нуждами, контекстом и угрозами вашей аудитории.

В вашем пространстве Shira вы можете:
- [создавать тесты](#create-quizzes);
- [настраивать параметры приватности](#privacy);
- [use quizzes to assess or train](#quiz-mode)
- [публиковать тесты и отменять публикацию](#publish-unpublish);
- [редактировать тесты](#edit-quizzes);
- [создавать копии тестов](#duplicate-quiz);
- [удалять тесты](#delete-quiz).

## Создание тестов {/* #create-quizzes */}
To create a quiz, you have two options:
1. You can create a quiz from scratch.
2. You can use a ready-made [template](/templates). If you use a template, you can use it as is or adapt it to your specific context and needs.

In both cases, you must:
1. дать название тесту;
2. установить настройки приватности теста.

### Название теста {/* #name */}
Выбранное вами название напоминает и вам, и учащимся суть теста (например, «Обучение персонала Q4», «Самые распространенные атаки 2026 года» и т.д.). Название теста видно учащимся:
- в email, которое учащиеся получают, когда вы назначаете им тест (только для [закрытых тестов](#privacy));
- на экране приветствия, когда учащиеся проходят тест.

### Приватность теста {/* #privacy */}
Есть два типа приватности теста: открытый и закрытый.

**Выбранные настройки приватности теста нельзя изменить**. Если нужен существующий тест, но с другими настройками, нужно создать его копию.

**Открытые тесты**
* Открытый тест может пройти всякий, у кого есть ссылка.
* Ссылка — уникальный адрес теста, который используют учащиеся. Пример ссылки: `https://quiz.shira.app/quiz/e57e406fdf46546786rru04676352bf0aff1c04f68. Ссылка не меняется, даже если вы публикуете тест и отменяете его публикацию несколько раз.
* Учащиеся, которые выполняют открытые тесты, сохраняют анонимность. Это значит, что в [Результатах](/results) вы не можете идентифицировать учащихся.

**Закрытые тесты**
* Только учащиеся, зарегистрированные в вашем пространстве, могут проходить тест. Подробнее о зарегистрированных учащихся см. [здесь](/learners#registered).
* Когда зарегистрированному учащемуся предлагают закрытый тест, он получает email с уникальной ссылкой. Она позволяет видеть, кто проходит тест и с каким результатом.

### Quiz mode {/* #quiz-mode */}
In quiz settings, you can select the quiz mode. You should select the quiz mode based on your objectives with this quiz:
* Learning mode: learners receive immediate feedback and explanations after each answer to help them improve their phishing detection skills. This is the default mode for new quizzes and should be used for training purposes.
* Assessment mode: learners test their phishing detection skills without feedback or explanations to measure their actual performance level. This should be used to measure learners' detection skills in the most reliable way possible. It is especially useful for regular assessment of a team or organization's preparedness level, or at the beginning and end of a training program to measure the impact of the training.

## Добавление вопросов в ваш викторин {/* #questions */}

Вы можете добавлять в свой тест вопросы, создавая их сами или импортируя готовые шаблоны из библиотеки. [Подробнее о вопросах](/questions).

## Опубликование и распечатывание викторины {/* #publish-unpublish */}
Публикация теста означает, что вы делаете его доступным для учащихся.

Вы можете отменить публикацию теста. Тогда учащиеся не смогут его проходить, а ссылка будет вести на страницу с ошибкой.

<Note>
Если вы разблокируете викторину *, в то время как * обучающийся принимает его, ученик увидит сообщение об ошибке в конце викторины, когда они попытаются представить свои ответы, и их представление будет потеряно.
</Note>

## Редактирование викторины {/* #edit-quizzes */}
Вы можете редактировать любой тест независимо от того, опубликован он или нет, в том числе:
- добавлять к тесту новые вопросы;
- редактировать существующие вопросы теста;
- изменять порядок вопросов: тот порядок, который вы видите в своем пространстве, соответствует тому, что видят учащиеся при прохождении теста;
- удалять вопросы (после удаления восстановить вопрос невозможно).

<Note>
Если некоторые ученики уже взяли викторину, редактирование этого викторина может повлиять на надежность [результатов викторины](/results).
</Note>

## Дублирование викторины {/* #duplicate-quiz */}
Можно создавать точные копии существующих тестов.

После дублирования исходный тест и новый тест становятся независимыми друг от друга. Вы можете редактировать или удалять один из них, это не повлияет на другой. **Результаты, связанные с исходным тестом, *не будут* перенесены в новую копию теста**.

При создании копии теста вы можете изменить настройки его приватности (открытый или закрытый).

## Удаление викторины {/* #delete-quiz */}
Удаление теста означает, что тест, все вопросы в нём и связанные с ним [результаты](/results) будут удалены из вашего пространства.

<Warning>
Удаление викторины является постоянным: после удаления викторина и ее результаты не могут быть восстановлены!
</Warning>

## Exporting and importing quizzes {/* #export-import */}
Each quiz can be exported as a .zip file. The .zip file contains the quiz's metadata, the content of each question, the assets (such as images) used in the questions.

Exporting a quiz can be useful to:
* Share a quiz with another Space without having to make it publicly available through the template library.
* Keep a backup of the quiz for future use.

In order to import a quiz from a .zip file, the .zip file must be structured exactly as it was exported. The correct structure is:
```
quiz_name.zip
├── metadata.json -> quiz info (name) + question array of [name, app, isPhishing]
└── questions/
    ├── question_name_1.html
    └── question_name_2.html
└── assets/
    ├── image-1.png
    └── image-2.jpg
```

If the .zip file itself or the file it contains are not properly formatted, the import will fail.
