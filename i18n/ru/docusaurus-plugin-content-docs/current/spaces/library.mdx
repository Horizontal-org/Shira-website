# Template Library
The template library is where you can find ready-made quiz and question templates, allowing you to get started with Shira as quickly and seamlessly as possible, without having to build your quizzes from scratch.

<Note>
Использование шаблона из библиотеки создает копию шаблона в вашем пространстве. После использования шаблона оригинальный шаблон и викторина или вопрос в вашем пространстве отделены и независимы друг от друга.
</Note>

## Шаблоны для вопросов {/* #quiz-templates */}
Шаблоны Quiz - это готовые викторины, которые вы можете импортировать в свое пространство.

Чтобы начать с шаблонов quiz:
1. В домашнем экране вашего Пространства нажмите на "Используй шаблон викторины", чтобы открыть библиотеку.
2. Поиск библиотеки для шаблона, подходящего для ваших нужд. Вы можете отфильтровать список quizzes, доступных:
   - язык: некоторые викторины включают несколько языков, особенно тех, которые предназначены для пользователей в многоязычных регионах.
   - теги: например, «уровень: легкий», «HR Team», «только для мобильных».
   - автор: организация, которая внесла в библиотеку шаблон quiz
3. После того, как вы нашли правильный шаблон, нажмите «Использовать шаблон», чтобы импортировать его в ваше пространство.
4. Установите новый викторин [название](/quizzes#name) и [приват](/quizzes#privacy).
5. Оттуда вы можете:
   - Начните использовать викторину как есть, не внося никаких изменений.
   - Настройте его, чтобы соответствовать вашим конкретным потребностям.

## Шаблоны для вопросов {/* #question-templates */}
Шаблоны вопросов - это готовые вопросы, которые вы можете импортировать в существующий викторин в вашем пространстве.

Чтобы начать с шаблонов вопросов:
1. Внутри викторины в вашем Пространстве нажмите на «Использовать шаблон вопроса», чтобы открыть библиотеку.
2. Поиск библиотеки для шаблона, подходящего для ваших нужд. Вы можете отфильтровать список вопросов, доступных:
   - язык: некоторые вопросы включают несколько языков, особенно тех, которые предназначены для пользователей в многоязычных регионах.
   - теги: например, «уровень: легкий», «мягкая ссылка», «выдающаяся личность» (CEO).
   - [apps](/questions#app): вопросы электронной почты или сообщений.
   - тип: фишинг или законные вопросы.
3. После того, как вы нашли правильный шаблон, выберите приложение, которое вы хотели бы использовать, и нажмите «Добавить до quiz», чтобы импортировать его в свой тест.
4. Оттуда вы можете:
   - Начните использовать вопрос как таковой, не внося никаких изменений.
   - Настройте его, чтобы соответствовать вашим конкретным потребностям.

<Note>
Шаблоны вопросов часто уже включают [объяснения](/questions#explanations), но вы можете добавлять свои собственные объяснения или редактировать те, которые приходят в шаблон.
</Note>

## Представление шаблонов {/* #submitting-templates */}
Любой, у кого есть Шира, может представить шаблоны в библиотеку. Это отличный способ сделать ресурсы, которые вы создаете в Шире, доступными для людей, с которыми вы работаете, или для более широкого сообщества пользователей.

Вопросы и шаблоны викторины могут быть представлены, нажав на кнопку «Представьте как шаблон» и заполнив информацию о шаблоне. Эта информация, включая название ресурса, краткое описание, языки, используемые в вопросе или викторине, и теги, позволяет другим легко найти ресурсы, которые будут им полезны.

Каждый представленный шаблон рассматривается человеком из команды Shira, чтобы убедиться, что он соблюдает наши [терминации и условия]{.

<Note>
После утверждения в библиотеке шаблон не может быть отредактирован или обновлен. Если вы хотите внести изменения в шаблон, пожалуйста, представьте обновленную версию шаблона и [email us](/contact) для запроса удаления старой версии.
</Note>
