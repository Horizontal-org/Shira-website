# Результаты

В разделе «Результаты» можно узнать, прошли ли пользователи ваш тест и насколько хорошо они с ним справились.

В разделе «Результаты» вы можете увидеть следующую информацию: **Число завершенных тестов** (сколько раз учащиеся прошли тест).
* Число завершенных открытых тестов не всегда равно числу учащихся, прошедших тест: учащиеся анонимны, значит, один человек может пройти тест несколько раз.
* Закрытый тест зарегистрированный учащийся может пройти только один раз.

**Средний балл**\
Средний балл всех учащихся, которые прошли тест.

** Скорость слияния ** Это процент учащихся, которые представили викторину из всех учеников, назначавших этот викторин. Завершение работы доступно только для частных викторин.

**Results by question** Это показывает вам средний балл, полученный всеми учащимися по каждому конкретному вопросу в тесте.

**Results by learner ** Это показывает вам список зарегистрированных учеников, которые завершили викторину и их счет на викторине. Результаты обучения доступны только для частных викторины.

<Note>
Если есть конкретные вещи, которые вы хотели бы отслеживать в результатах, [скажем,](/contact)!
</Note>

## Disabling Results
Results can be disabled in Space settings.

When you disabled Results:
* Analytics about how learners are doing on quizzes is no longer collected and saved.
* Analytics that was already collected prior to disabling Results remain in your Space.

Disabling Results can be useful for those who want to collect the absolute minimal amount of data about their learners. [Learn more about data privacy in Shira](/privacy-policy).
