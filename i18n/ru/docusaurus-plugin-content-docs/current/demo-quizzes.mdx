# Готовые викторины

Любой может использовать готовые викторины Shira’s бесплатно для создания своих навыков борьбы с фишингом:

<QuizLink className={classNames(global.buttonDark)}>Try a ready-made quiz now</QuizLink>

Готовые викторины обеспечивают базовый уровень настройки, в том числе позволяя пользователям:
* выбирать одно из привычных приложений;
* Выберите область работы, чтобы сделать содержание фишингового викторина более актуальным для них.
* Выберите их предпочтительный язык среди поддерживаемых языков
* Отобразить свое имя и электронную почту внутри викторины, чтобы каждое электронное письмо и сообщение выглядело как можно ближе к тому, с чем они столкнутся в реальной жизни.

Готовые викторины - отличный способ начать строить антифишинговые навыки. Тем не менее, антифишинговое обучение является наиболее эффективным, когда викторины адаптированы к конкретной цели обучения и включают в себя сценарии реальной жизни, соответствующий контекст и уникальный уровень деталей, тон и сложности организации. Чтобы достичь этого типа настройки, вам может понадобиться создать [Шиба Космос](/spaces).
