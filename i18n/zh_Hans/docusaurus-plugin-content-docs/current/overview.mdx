# 欢迎什叶派帮助中心!

什叶拉是一种反营养的教育工具。 利用什叶派对任何人进行培训,以查明通过电子邮件、SMS和图像传送的营养攻击.

在有控制的学习环境中,什叶拉提供尽可能与你的团队在实际生活中将获得的营养模拟。 什叶拉是围绕[研究显示](/phishing-quizzes)建造的,在建设抗营养技能方面,教育比向盒子里的学员发送的模拟营养化电子邮件更为有效.

在这一帮助中心,你将就如何利用什叶派培训你的团队或社区找到指导。 如果你的一些问题在这里得不到回答,[目标在触及!](/contact)

### Shira Space {/* #shira-space */}
A [Shira Space](/spaces)是为各小组和组织设计的,并提供诸如:
- 提出自己的问答,内容与你的团队特别相关.
- 抽取一个现成模板的图书馆,以在分钟内开始.
- setting your quizz's privacy as public (accessible to anyone with the quiz URL) or private (only accessible to learners registered with your organization).
- 追踪用户结果，了解用户在哪些方面可以提升。

export function FeaturedDocs() {
  const category = useCurrentSidebarCategory();
  const spacesItems = category.items.find(
    (item) =>
      item.type === 'category' &&
      item.items?.some(
        (child) => child.docId?.startsWith('spaces/')
      )
  ).items;

  return (
    <div className={classNames(global.shiraDocCards)}>
      {spacesItems.map((item, idx) => (
        <DocCard key={idx} item={item} />
      ))}
    </div>
  );
}
