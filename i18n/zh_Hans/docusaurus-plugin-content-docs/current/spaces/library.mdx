# 模拟图书馆
模板图书馆是你能够找到现成的问答模板的地方,使你能够尽快、无缝地从什叶拉开始,而不必从头.上 build.

<Note>
利用图书馆的一个模板,将模板复制到您的网站上。 在你使用模板之后,原始模板和基茨或问题在你空间是分开的,彼此独立.
</Note>

## 问题模版 {/* #quiz-templates */}
基茨模板是你可以进口到你的空间的现成qui.

开始采用静态模板:
1. 在您的航天舱内,点击“Use a quiz model”打开图书馆.
2. 寻找适合你们需要的模板。 您可通过以下方式过滤qui清单:
   - 语言:有些静态包括多种语言,特别是为多语区域用户设计的语言.
   - 标签:例如“一级:容易”,“人权小组”,“只机动”.
   - 作者:向图书馆提供问答模板的组织
3. 一旦您找到了正确的模板,就点击“Use模板”,将其输入你的空间.
4. 3. 确立新的[名称](/quizzes#name)和[原始](/quizzes#privacy).
5. 从那里可以:
   - 开始使用qui,不作任何改动.
   - 使其符合你们的具体需要.

## 问题模版 {/* #question-templates */}
问题模板是现成的问题,你可以将其输入现有的空间.

开始使用问答模板:
1. 在你空间的问答中,点击“使用问题模板”开放图书馆.
2. 寻找适合你们需要的模板。 2. 您可通过以下方式过滤问题单:
   - 语言:有些问题包括多种语文,特别是为多语区用户设计的语言.
   - 标签:例如,“水平:容易”,“恶意联系”,“太阳系冒犯”.
   - [apps](/questions#app): email or mesaging questions.
   - 类型:营养或合法问题.
3. 一旦你找到了正确的模板,就选择了你希望使用和点击“Add to quiz”将其输入你的询问.
4. 从那里可以:
   - 开始使用问题,不作任何改动.
   - 使其符合你们的具体需要.

<Note>
问题模板往往包括[解释](/questions#explanations),但你可以补充你自己的解释或照搬模板中的内容.
</Note>

## 排放模板 {/* #submitting-templates */}
任何拥有Shima空间的人都可以向图书馆提交模板。 这对于使你在希拉创造的资源能够提供给你与用户合作或广大用户社区的人来说,是一种巨大的方法.

可通过点击“作为模板的分机”纽吨和填充有关模板的信息来提交问题和基茨模板。 这种信息,包括资源名称、简短描述、问题中使用的语言或qui,使他人容易找到对他们有用的资源.

提交的每个模板都由什叶派小组的一名人员审查,以确保其遵守我们的[期限和条件](/terms-and-conditions)。 如果被拒绝,什叶派小组将分享一个简短的信息,概述拒绝的原因.

<Note>
一旦获准进入图书馆,就无法编辑或更新模板。 如果你希望对模板作改动,请提交该模板的最新版本,[电子邮箱:我们](/contact),要求删除旧版本.
</Note>
