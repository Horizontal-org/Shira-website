# Template Library
The template library is where you can find ready-made quiz and question templates, allowing you to get started with Shira as quickly and seamlessly as possible, without having to build your quizzes from scratch.

<Admonition type="备注">
Using a template from the library creates a copy of the template into your space. After you use a template, the original template and the quiz or question in your space are separate and independent from each other.
</Admonition>

## Quiz templates {/* #quiz-templates */}
Quiz templates are ready-made quizzes that you can import into your Space.

To get started with quiz templates:
1. In your Space's homescreen, click on "Use a quiz template" to open the library.
2. Search the library for a template suited to your needs. You can filter the list of quizzes available by:
   - language: some quizzes include multiple languages, especially those designed for users in multilingual regions.
   - tags: for example "level: easy", "HR team", "mobile-only".
   - author: the organization that contributed the quiz template to the library
3. Once you've found the right template, click "Use template" to import it into your Space.
4. Set the new quiz's [name](/quizzes#name) and [privacy](/quizzes#privacy).
5. From there, you can either:
   - Start using the quiz as is, without making any changes.
   - Customize it to match your specific needs.

<Admonition type="备注">
As of v2.1, only the Shira team can contribute quiz templates to the library. Other organizations will be able to contribute starting with v2.2. You can [read about new releases here](/release-notes).
</Admonition>

## Question templates {/* #question-templates */}
Question templates are ready-made questions that you can import into an existing quiz in your Space.

To get started with question templates:
1. Inside a quiz in your Space, click on "Use a question template" to open the library.
2. Search the library for a template suited to your needs. You can filter the list of questions available by:
   - language: some questions include multiple languages, especially those designed for users in multilingual regions.
   - tags: for example "level: easy", "malicious link", "CEO impersonation".
   - [apps](/questions#app): email or messaging questions.
   - type: phishing or legitimate questions.
3. Once you've found the right template, select the app you would like to use and click "Add to quiz" to import it into your quiz.
4. From there, you can either:
   - Start using the question as is, without making any changes.
   - Customize it to match your specific needs.

<Admonition type="备注">
Question templates often already include [explanations](/questions#explanations), but you can add your own explanations or edit the ones that come in the template.
</Admonition>
