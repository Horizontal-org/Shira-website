# 安全
什叶派使用者的安全和隐私对我们非常重要.

我们收集了有关希拉用户的绝对最低数据,只收集了我们掌握什叶拉特征和能力所需要的数据

我们实施行业标准措施,以确保所有用户数据的保密性、完整性和可用性。 关于我们如何处理Shiraumi数据(https://space.shira.app和https://quiz.shira.app)的更多信息,请见[隐私政策](/privacy-policy).

此外,什叶拉是开放源,因此任何人都能够[审查授权该信的法典](https://github.com/Horizontal-org/shira).

最后,在公布主要的新特点之前,我们委托独立的第三方保安公司进行安全审计。 这些审计的结果可公开查阅:
