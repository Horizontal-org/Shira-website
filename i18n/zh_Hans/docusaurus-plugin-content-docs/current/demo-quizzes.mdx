# 2. 易燃液体

任何人都可以利用什叶拉的现成qui,自由建设其营养技能:

<QuizLink className={classNames(global.buttonDark)}>Try a ready-made quiz now</QuizLink>

阅读式静态提供了基本的定制水平,包括让用户:
* 选择每天使用的仪器.
* • 启动“工作领域”,使营养qui的内容与他们更加相关.
* 在所支持的语言中选取其优先语言
* 显示其姓名和电子邮件,使每一电子邮件和电文尽可能与他们在实际生活中将面临的情况相似.

深造的烟.是开始建设抗营养技能的重要途径。 然而,如果静电符合具体的学习目标,并纳入现实生活情景、相关背景和组织的独特细节、基调和复杂程度,抗营养素培训就最为有效。 为了实现这种定制,你可能需要建立一个[Sira Space](/spaces).
