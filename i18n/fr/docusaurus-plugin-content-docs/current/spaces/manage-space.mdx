# Gestion de votre espace

Un espace est l'endroit central de Shira pour construire vos campagnes d'éducation phénoménale:
- Un espace est où vous **créez des quizz, gérez les apprenants et voyez des résultats** pour vos apprenants.
- **Dans votre espace, vous pouvez avoir beaucoup [Quizzes] (/quizzes)**. Par exemple, vous pouvez créer un quiz axé sur le phishing de courriel et un autre sur le phishing de SMS; ou vous pouvez créer un quiz à bord de nouveaux membres de l'équipe, et créer un quiz séparé pour former votre équipe chaque trimestre.
- **Chaque quiz est composé de [Questions] (/questions)**. Une question montre un courriel ou un message et demande à l'apprenant de décider si le message ressemble à un phishing ou semble légitime. L'apprenant a également la possibilité de répondre "Je ne sais pas". Vous pouvez construire vos questions à partir de zéro ou tirer des modèles de [la Bibliothèque] (/templates).
- **Quelqu'un qui prend un quiz est appelé un [Apprentisseur](/learners)**. Il y a des apprenants inscrits (qui peuvent avoir besoin de rejoindre votre espace pour prendre des quizz privés) et des apprenants anonymes (toute personne qui prend un quiz public en utilisant l'URL du quiz).
- Après que les apprenants prennent un quiz, **la section [Résultats](/results) montre comment ils ont fait sur le quiz**.

## Paramètres spatiaux {/* #settings */}
Dans vos paramètres spatiaux, vous pouvez:
* mettre à jour l'adresse courriel associée à votre compte
* mettez à jour votre mot de passe
* gérer [votre plan, abonnement et informations de paiement] (/plans)

## Permissions {/* #permissions */}
* Par défaut, un seul utilisateur d'administration peut accéder à un espace. [Enterprise](/pricing) les utilisateurs peuvent ajouter plus d'administrateurs (chacun avec leur propre compte et leurs identifiants) en [contactant nous](/contact).
* Seuls les administrateurs peuvent accéder à votre tableau de bord Space. Les apprentis n'ont jamais accès au tableau de bord de l'espace, aux quizz ou aux résultats.

Ce tableau résume ce que les apprenants et les administrateurs peuvent faire dans un espace Shira:
| Permission                 | Apprenant.e | Admin |
| -------------------------- | ----------- | ----- |
| Prenez Quiz                | Yes         | Yes   |
| Se connecter à l ' espace  | No          | Yes   |
| Créer et gérer les Quizzes | No          | Yes   |
| Voir les résultats         | No          | Yes   |
| Créer et gérer l'espace    | No          | No    |


## Deleting your space {/* #deleting-your-space */}
Il est actuellement impossible de supprimer votre espace sans notre assistance. Si vous souhaitez supprimer votre espace, [contactez-nous ici] (/contact).
