# Gérer votre espace

Un espace est l'endroit central à Shira pour construire vos campagnes de sensibilisation au phishing :
- Un Espace est l'endroit où vous **créez des quiz, gérez les apprenants et consultez les résultats** de vos apprenants.
- **Dans votre espace, vous pouvez créer plusieurs [Quiz](/quizzes)**. Par exemple, vous pouvez créer un quiz sur l'hameçonnage par e-mail et un autre sur l'hameçonnage par SMS ; ou encore, vous pouvez créer un quiz pour l'intégration des nouveaux membres de l'équipe et un autre pour former votre équipe chaque trimestre.
- **Chaque quiz est composé de questions(/questions)**. Une question présente un courriel ou un message et demande à l'apprenant de déterminer s'il s'agit d'une tentative d'hameçonnage ou d'un message légitime. L'apprenant peut également répondre « Je ne sais pas ». Vous pouvez créer vos questions vous-même ou utiliser des modèles de [la bibliothèque](/templates).
- **Une personne qui passe un quiz est appelée un [Apprenant](/learners)**. Il existe des Apprenants inscrits (qui peuvent avoir besoin de rejoindre votre Espace pour passer des quiz privés) et des Apprenants anonymes (toute personne qui passe un quiz public en utilisant l'URL du quiz).
- Après que les apprenants aient passé un quiz, **la [section Résultats](/results) montre comment ils se sont comportés au quiz**.

## Paramètres d'espace (#paramètres) {/* #space-settings-settings */}
Dans les paramètres de votre Espace, vous pouvez :
* Mettez à jour l'adresse e-mail associée à votre compte
* Mettez à jour votre mot de passe
* gérer [votre forfait, votre abonnement et vos informations de paiement](/plans)

## Permissions {/* #permissions */}
* Par défaut, un seul utilisateur administrateur peut accéder à un espace. Les utilisateurs [Enterprise](/pricing) peuvent ajouter d'autres administrateurs (chacun avec son propre compte et ses propres identifiants) en [nous contactant](/contact).
* Seuls les administrateurs peuvent accéder à votre tableau de bord Espace. Les apprenants n'ont jamais accès au tableau de bord Espace, aux quiz ni aux résultats.

Ce tableau récapitule ce que les apprenants et les administrateurs peuvent faire dans un espace Shira :
| Permission                | Apprenant.e | Administrateur |
| ------------------------- | ----------- | -------------- |
| Répondre au quiz          | Oui         | Oui            |
| Se connecter à l ' espace | Non         | Yes            |
| Créer et gérer des Quiz   | Non         | Yes            |
| Voir les résultats        | No          | Yes            |
| Créer et gérer un espace  | No          | No             |


## Supprimer votre espace {/* #deleting-your-space */}
Il est actuellement impossible de supprimer votre Espace sans notre aide. Si vous souhaitez supprimer votre Espace, [contactez-nous ici](/contact).
