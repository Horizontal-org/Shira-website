# Template Library
The template library is where you can find ready-made quiz and question templates, allowing you to get started with Shira as quickly and seamlessly as possible, without having to build your quizzes from scratch.

<Note>
Using a template from the library creates a copy of the template into your space. After you use a template, the original template and the quiz or question in your space are separate and independent from each other.
</Note>

## Quiz templates {/* #quiz-templates */}
Quiz templates are ready-made quizzes that you can import into your Space.

To get started with quiz templates:
1. In your Space's homescreen, click on "Use a quiz template" to open the library.
2. Search the library for a template suited to your needs. You can filter the list of quizzes available by:
   - language: some quizzes include multiple languages, especially those designed for users in multilingual regions.
   - tags: for example "level: easy", "HR team", "mobile-only".
   - author: the organization that contributed the quiz template to the library
3. Once you've found the right template, click "Use template" to import it into your Space.
4. Set the new quiz's [name](/quizzes#name) and [privacy](/quizzes#privacy).
5. From there, you can either:
   - Start using the quiz as is, without making any changes.
   - Customize it to match your specific needs.

## Modèles de questions {/* #question-templates */}
Question templates are ready-made questions that you can import into an existing quiz in your Space.

To get started with question templates:
1. Inside a quiz in your Space, click on "Use a question template" to open the library.
2. Search the library for a template suited to your needs. You can filter the list of questions available by:
   - language: some questions include multiple languages, especially those designed for users in multilingual regions.
   - tags: par exemple "niveau: facile", "malicious link", "CEO impersonation".
   - [apps] (/questions#app): e-mail ou messages.
   - type: questions phénoménales ou légitimes.
3. Une fois que vous avez trouvé le bon modèle, sélectionnez l'application que vous souhaitez utiliser et cliquez sur "Ajouter au quiz" pour l'importer dans votre quiz.
4. De là, vous pouvez :
   - Commencez à utiliser la question comme c'est, sans faire de changements.
   - Personnalisez-le pour répondre à vos besoins spécifiques.

<Note>
Les modèles de questions incluent souvent [explications](/questions#explanations), mais vous pouvez ajouter vos propres explications ou modifier celles qui viennent dans le modèle.
</Note>

## Soumettre des modèles {/* #submitting-templates */}
Toute personne avec un espace Shira peut soumettre des modèles à la bibliothèque. C'est une excellente façon de mettre les ressources que vous créez à Shira à la disposition des personnes avec ou de la communauté plus large des utilisateurs.

Les questions et les modèles de quiz peuvent être soumis en cliquant sur le bouton "Soumettre comme modèle" et en remplissant les informations sur le modèle. Cette information, y compris le nom de la ressource, une brève description, les langues utilisées dans la question ou le quiz, et les étiquettes, permet aux autres de trouver des ressources qui leur seront utiles.

Chaque modèle présenté est examiné par un humain de l'équipe de Shira pour s'assurer qu'il respecte nos [termes et conditions] (/terms-and-conditions). Si rejeté, l'équipe de Shira partagera un court message décrivant la raison du rejet.

<Note>
Une fois approuvé dans la bibliothèque, un modèle ne peut être modifié ou mis à jour. Si vous souhaitez modifier un modèle, veuillez soumettre une version mise à jour du gabarit et [email us](/contact) pour demander un retrait de l'ancienne version.
</Note>
