# Bibliothèque de modèles
La bibliothèque de gabarits est là où vous pouvez trouver des modèles de quiz et de questions prêts, vous permettant de commencer avec Shira aussi rapidement et sans couture que possible, sans avoir à construire vos quizzes à partir de zéro.

<Note>
L'utilisation d'un modèle de la bibliothèque crée une copie du modèle dans votre espace. Après avoir utilisé un modèle, le modèle original et le quiz ou la question dans votre espace sont séparés et indépendants les uns des autres.
</Note>

## Modèles de Quiz {/* #quiz-templates */}
Les modèles Quiz sont des quizz faits prêts que vous pouvez importer dans votre espace.

Pour commencer avec des modèles de quiz:
1. Dans l'écran d'accueil de votre espace, cliquez sur « Utiliser un gabarit de quiz » pour ouvrir la bibliothèque.
2. Recherchez la bibliothèque pour un modèle adapté à vos besoins. Vous pouvez filtrer la liste des quizz disponibles par:
   - langue: certains quizzes comprennent plusieurs langues, en particulier celles conçues pour les utilisateurs dans les régions multilingues.
   - tags: par exemple "niveau: facile", "RH team", "mobile-only".
   - auteur: l'organisation qui a fourni le modèle de quiz à la bibliothèque
3. Une fois que vous avez trouvé le bon modèle, cliquez sur "Utiliser le modèle" pour l'importer dans votre espace.
4. Définir le nouveau quiz [nom] (/quizzes#name) et [privacy](/quizzes#privacy).
5. De là, vous pouvez :
   - Commencez à utiliser le quiz comme il est, sans faire de changements.
   - Personnalisez-le pour répondre à vos besoins spécifiques.

## Modèles de questions {/* #question-templates */}
Les modèles de questions sont des questions prêtes que vous pouvez importer dans un quiz existant dans votre espace.

Pour commencer avec des modèles de questions:
1. À l'intérieur d'un quiz dans votre espace, cliquez sur "Utilisez un modèle de questions" pour ouvrir la bibliothèque.
2. Recherchez la bibliothèque pour un modèle adapté à vos besoins. Vous pouvez filtrer la liste des questions disponibles par:
   - langue: certaines questions incluent plusieurs langues, en particulier celles conçues pour les utilisateurs dans les régions multilingues.
   - tags: par exemple "niveau: facile", "malicious link", "CEO impersonation".
   - [apps] (/questions#app): e-mail ou messages.
   - type: questions phénoménales ou légitimes.
3. Une fois que vous avez trouvé le bon modèle, sélectionnez l'application que vous souhaitez utiliser et cliquez sur "Ajouter au quiz" pour l'importer dans votre quiz.
4. De là, vous pouvez :
   - Commencez à utiliser la question comme c'est, sans faire de changements.
   - Personnalisez-le pour répondre à vos besoins spécifiques.

<Note>
Les modèles de questions incluent souvent [explications](/questions#explanations), mais vous pouvez ajouter vos propres explications ou modifier celles qui viennent dans le modèle.
</Note>

## Soumettre des modèles {/* #submitting-templates */}
Toute personne avec un espace Shira peut soumettre des modèles à la bibliothèque. C'est une excellente façon de mettre les ressources que vous créez à Shira à la disposition des personnes avec ou de la communauté plus large des utilisateurs.

Les questions et les modèles de quiz peuvent être soumis en cliquant sur le bouton "Soumettre comme modèle" et en remplissant les informations sur le modèle. Cette information, y compris le nom de la ressource, une brève description, les langues utilisées dans la question ou le quiz, et les étiquettes, permet aux autres de trouver des ressources qui leur seront utiles.

Chaque modèle présenté est examiné par un humain de l'équipe de Shira pour s'assurer qu'il respecte nos [termes et conditions] (/terms-and-conditions). Si rejeté, l'équipe de Shira partagera un court message décrivant la raison du rejet.

<Note>
Une fois approuvé dans la bibliothèque, un modèle ne peut être modifié ou mis à jour. Si vous souhaitez modifier un modèle, veuillez soumettre une version mise à jour du gabarit et [email us](/contact) pour demander un retrait de l'ancienne version.
</Note>
