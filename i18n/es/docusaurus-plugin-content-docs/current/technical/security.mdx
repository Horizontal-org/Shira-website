# Seguridad
La seguridad y privacidad de los usuarios de Shira es muy importante para nosotros.

Recopilamos la cantidad mínima absoluta de datos sobre usuarios de Shira, y sólo recopilamos datos que necesitamos para potenciar las funciones y capacidades de Shira

Implementamos medidas estándar de la industria para garantizar la confidencialidad, integridad y disponibilidad de todos los datos del usuario. Para obtener más información sobre cómo manejamos los datos en la nube de Shira (en https://space.shira.app y https://quiz.shira.app), consulte [nuestra política de privacidad](/privacy-policy). Las organizaciones con preocupaciones especiales de privacidad pueden [apropiarse de su propia instancia de Shira](/self-hosting).

Además, Shira es de código abierto para que cualquiera pueda [ver el código que potencia la aplicación](https://github.com/Horizontal-org/shira).

Por último, antes de publicar nuevas características importantes, encargamos auditorías de seguridad por empresas independientes de seguridad de terceros. Los resultados de estas auditorías están disponibles públicamente:
- Julio 2023: [Auditoría de seguridad por Subgraph en Shira 1.0](/assets/subgraph-audit-july-2023.pdf)
- Junio 2026: [Auditoría de seguridad por Convocation Research and Design Labs en Shira 2.0](/assets/convocation-audit-june-2026.pdf)
