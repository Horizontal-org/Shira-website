# Exámenes listos

Cualquier persona puede utilizar los cuestionarios hechos por Shira de forma gratuita para construir sus habilidades anti-phishing:

<QuizLink className={classNames(global.buttonDark)}>Try a ready-made quiz now</QuizLink>

Las preguntas preparadas proporcionan un nivel básico de personalización, incluso permitiendo a los usuarios:
* Seleccione las aplicaciones que usan todos los días.
* Escoja un “campo de trabajo” para que el contenido de la prueba de phishing sea más relevante para ellos.
* Seleccione su idioma preferido entre los idiomas compatibles
* Mostrar su nombre y correo electrónico dentro del cuestionario, para hacer que cada correo electrónico y mensaje se vean lo más parecido posible a lo que enfrentarán en la vida real.

Los cuestionarios listos son una gran manera de empezar a construir habilidades anti-phishing. Sin embargo, el entrenamiento anti-phishing es más eficaz cuando los cuestionarios se adaptan a un objetivo de aprendizaje específico e incorpora escenarios de la vida real, contexto relevante y detalles únicos, tono y nivel de complejidad de una organización. Para lograr este tipo de personalización, es posible que necesite crear un [Shira Space](/spaces).

Si necesita ayuda para evaluar si crear un espacio es el camino correcto para su organización, [contáctenos](/contact)!
