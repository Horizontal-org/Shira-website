# ¡Bienvenido al Centro de Ayuda Shira!

Shira es una herramienta de educación anti phishing. Usa Shira para capacitar a cualquier persona para que identifique ataques de phishing enviados a través de correo electrónico, SMS, y aplicaciones de mensajería.

Shira ofrece, en un entorno de aprendizaje controlado, simulaciones de phishing que son lo más similares posible a lo que tu equipo recibirá en la vida real. Shira se basa en [investigaciones que demostraron](/phishing-quizzes) que cuando se trata de desarrollar habilidades contra el phishing, la educación es mucho más efectiva que enviar correos de phishing simulados a las bandejas de entrada de quienes aprenden.

En este Centro de Ayuda, encontrará orientación sobre cómo utilizar Shira para entrenar a su equipo o comunidad. Si algunas de sus preguntas no son respondidas aquí, [¡en contacto!](/contact)

### Shira Space {/* #shira-space */}
A [Shira Space](/spaces) está diseñado para equipos y organizaciones y ofrece características avanzadas como:
- crear sus propias preguntas de examen, con contenido específicamente relevante para su equipo.
- tapping en una biblioteca de plantillas preparadas para empezar en minutos.
- setting your quizz's privacy as public (accessible to anyone with the quiz URL) or private (only accessible to learners registered with your organization).
- monitorear los Resultados de las personas usuarias para entender dónde tus personas usuarias pueden mejorar.

export function FeaturedDocs() {
  const category = useCurrentSidebarCategory();
  const spacesItems = category.items.find(
    (item) =>
      item.type === 'category' &&
      item.items?.some(
        (child) => child.docId?.startsWith('spaces/')
      )
  ).items;

  return (
    <div className={classNames(global.shiraDocCards)}>
      {spacesItems.map((item, idx) => (
        <DocCard key={idx} item={item} />
      ))}
    </div>
  );
}
