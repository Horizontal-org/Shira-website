# الاستضافة الذاتية

Shira is [open-source](https://github.com/Horizontal-org/shira) and it's distributed under an MIT License. We maintain a cloud instance of Shira for our partners, but anyone can self-host their own instance.

يرجى [التواصل معنا](/contact) إذا كنتم مهتمين باستضافة Shira ذاتياً. للمستخدمين ذوي الخبرة، يمكن القيام بذلك عبر: [https://github.com/Horizontal-org/shira](https://github.com/Horizontal-org/shira). سنقوم قريباً بنشر دليل إرشادي خاص بالاستضافة الذاتية.
