# الأمان
إن أمن وخصوصية مستخدمي شيرا مهمتان جدا بالنسبة لنا.

نحن نجمع الحد الأدنى المطلق من البيانات عن مستعملي شيرا، وفقط جمع البيانات التي نحتاجها لتشغيل السمات والقدرات في شيرا

وننفذ تدابير معيارية في مجال الصناعة لضمان السرية والنزاهة وتوافر جميع بيانات المستخدمين. وللحصول على مزيد من المعلومات عن كيفية التعامل مع البيانات المتعلقة بسحابة شيرا (في الموقعين https://space.shira.app و https://quiz.shira.app)، يرجى الاطلاع على [سياسة خصوصية لدينا] (/privacy-policy).

In addition, Shira is open-source so anyone can [review the code that powers the app](https://github.com/Horizontal-org/shira).

وأخيرا، وقبل إطلاق سمات جديدة رئيسية، نكلف شركات أمنية مستقلة تابعة لأطراف ثالثة بإجراء مراجعة أمنية. وتتاح نتائج عمليات مراجعة الحسابات هذه للجمهور:
- July 2023: [security audit by Subgraph on Shira 1.0](/assets/subgraph-audit-july-2023.pdf)
- June 2026: [security audit by Convocation Research and Design Labs on Shira 2.0](/assets/convocation-audit-june-2026.pdf)
